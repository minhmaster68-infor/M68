Phần I

KIẾN THỨC TRỌNG TÂM (TỪ TUẦN 1 ĐẾN TUẦN 7)

📘 ĐẠI SỐ CỐT LÕI

  • Đơn thức: Chỉ gồm tích của số và biến. Bậc = Tổng số mũ các biến.
  • Đa thức: Thu gọn hết → Lấy bậc của hạng tử cao nhất. Hằng số khác 0 có bậc là 0.
  • Nhân đơn/đa thức: Chú ý dấu: (−) × (−) = (+); (−) × (+) = (−).
  • Hằng đẳng thức bậc hai:
    • (A + B)2 = A2 + 2AB + B2
    • (A − B)2 = A2 − 2AB + B2
    • A2 − B2 = (A − B)(A + B)

📐 HÌNH HỌC TỨ GIÁC

  • Tổng 4 góc tứ giác: Luôn bằng 360°.
  • Hình thang cân: Hình thang có 2 góc kề một đáy bằng nhau HOẶC 2 đường chéo bằng nhau.
  • Hình bình hành: Cạnh đối // và bằng nhau, 2 đường chéo cắt nhau tại trung điểm mỗi đường.
  • Hình chữ nhật: HBH có 1 góc vuông HOẶC 2 đường chéo bằng nhau.
  • Hình thoi: HBH có 2 cạnh kề bằng nhau HOẶC 2 đường chéo vuông góc.
  • Hình vuông: Vừa là hình chữ nhật vừa là hình thoi.
Phần II

GIẢI CHI TIẾT 28 CÂU TRẮC NGHIỆM (KÈM BẮT BẪY)

Câu 1: Biểu thức nào sau đây là đơn thức? Đáp án: A
A. x2y3
B. x2 + y3
C. x2 − y3
D. x2 / y3
Xem giải thích
Đơn thức là biểu thức đại số chỉ gồm một số, một biến, hoặc một tích giữa các số và các biến. Biểu thức B, C có phép cộng/trừ (đa thức), biểu thức D chứa biến ở mẫu nên không phải đơn thức. Chọn A.
Câu 2: Phần hệ số của đơn thức 12x2y2z4 là: Đáp án: B
A. 12x2y2z4
B. 12
C. x2y2z4
D. 12xyz
Xem giải thích
Phần hệ số là phần số thực đứng trước phần biến: ở đây là số 12. Chọn B.
Câu 3: Bậc của đơn thức 3x2y3 là: Đáp án: D
A. 6
B. 3
C. 4
D. 5
Xem giải thích
Bậc của đơn thức có hệ số khác 0 là tổng số mũ của tất cả các biến: số mũ của x là 2, của y là 3 → Bậc = 2 + 3 = 5. Chọn D.
Câu 4: Đa thức A = 5x2y + xy3 có bậc là: Đáp án: B
A. 5
B. 4
C. 3
D. 2
Xem giải thích
Đa thức đã thu gọn. Hạng tử 5x2y có bậc là 2 + 1 = 3. Hạng tử xy3 có bậc là 1 + 3 = 4. Hạng tử có bậc cao nhất là 4 nên bậc của đa thức là 4. Chọn B.
Câu 5: Đa thức B = 7 + 4x có bậc mấy? Đáp án: A
A. 1
B. 2
C. 3
D. 4
Xem giải thích
Hạng tử 4x có bậc là 1 (vì x = x1). Hạng tử 7 có bậc 0. Bậc cao nhất là 1. Chọn A.
Câu 6 (BẢO BẢO ĐÃ KHOANH SAI TRONG ĐỀ CƯƠNG): Đa thức C = 4x2y3 − xy2 + 3 − 4x2y3 + xy2 có bậc là: Đáp án đúng: A (0)
A. 0 (ĐÚNG)
B. 1 (BẢO BẢO ĐÃ CHỌN SAI)
C. 3
D. 4
Giải thích lỗi sai & Khắc phục

Bước 1: Thu gọn Nhóm các hạng tử đồng dạng:

C = (4x2y3 − 4x2y3) + (−xy2 + xy2) + 3 = 0 + 0 + 3 = 3.

Bước 2: Tìm bậc Sau khi thu gọn, đa thức chỉ còn lại số 3 (hằng số khác 0).

Câu 11: Giá trị a, b thỏa mãn (x − 3)(2x2 + ax + b) = 2x3 − 8x2 + 9x − 9 là: Đáp án: A
A. a = −2, b = 3

Phần III

TỰ LUẬN ĐẠI SỐ: RÈN KỸ NĂNG BIẾN ĐỔI KHÔNG SAI DẤU

Bài 1: Đơn thức và tính giá trị
Cho đơn thức: A = 2xy2 × (½ x2y2x).
Xem lời giải từng bước

a) Thu gọn: A = [2 × ½] × (x × x2 × x) × (y2 × y2) = 1 × x4y4 = x4y4.

b) Bậc, hệ số: Hệ số là 1; Phần biến là x4y4; Bậc là 4 + 4 = 8.

c) Tính giá trị tại x = 2, y = −1:

A = (2)4 × (−1)4 = 16 × 1 = 16. (Lưu ý: số âm mũ chẵn ra kết quả dương!)

d) Chứng minh A không âm:

Ta có A = x4y4 = (x2y2)2 ≥ 0 với mọi số thực x, y. Vậy A luôn không âm.

Bài 2: Thu gọn và tìm bậc của đa thức
Thu gọn và tìm bậc của các đa thức:
a) A = 3x2y + xy2 + xy2 − x2y + 2xy
b) B = 2xy2 + 4xy − xy2 − x2y + xy
c) C = 5x2y3 − 2xy2 − 2xy2 − x2y3 + xy2
Xem lời giải từng bước

a) A = (3x2y − x2y) + (xy2 + xy2) + 2xy = 2x2y + 2xy2 + 2xy.
→ Bậc của đa thức A là 3.

b) B = (2xy2 − xy2) + (4xy + xy) − x2y = xy2 − x2y + 5xy.
→ Bậc của đa thức B là 3.

c) C = (5x2y3 − x2y3) + (−2xy2 − 2xy2 + xy2) = 4x2y3 − 3xy2.
→ Hạng tử bậc cao nhất là 4x2y3 có bậc 2 + 3 = 5. Vậy bậc của C là 5.

Bài 3: Tìm đa thức C
Cho: A = x2 + 3y2 − 2x3y2 và B = 3x2 + 3y2 + 2x3y2.
Xem lời giải từng bước

a) C = A + B:

C = (x2 + 3y2 − 2x3y2) + (3x2 + 3y2 + 2x3y2) = 4x2 + 6y2.

b) C + A = B → C = B − A:

C = (3x2 + 3y2 + 2x3y2) − (x² + 3y² − 2x³y²)

C = 3x2 + 3y2 + 2x3y2 − x2 − 3y2 + 2x3y2 = 2x2 + 4x3y2.

c) C + B = A → C = A − B:

C = (x2 + 3y2 − 2x3y2) − (3x² + 3y² + 2x³y²)

C = x2 + 3y2 − 2x3y2 − 3x2 − 3y2 − 2x3y2 = −2x2 − 4x3y2.

Bài 4: Chứng minh hai đa thức không cùng nhận giá trị âm
Cho hai đa thức: P = x2 + 2xy − y2 và Q = x2 − 2xy + 4y2.
Xem lời giải từng bước

Chiến thuật Xét tổng hai đa thức P + Q:

P + Q = (x2 + 2xy − y2) + (x2 − 2xy + 4y2)

P + Q = (x2 + x2) + (2xy − 2xy) + (−y2 + 4y2) = 2x2 + 3y2.

Vì x2 ≥ 0 và y2 ≥ 0 với mọi số thực x, y, nên:

2x2 + 3y2 ≥ 0 với mọi x, y → Tổng P + Q không âm.

Nếu cả P và Q cùng nhận giá trị âm thì tổng của chúng phải là một số âm (mâu thuẫn). Do đó, không tồn tại giá trị nào của x và y để hai đa thức P và Q cùng có giá trị âm (đpcm).

Bài 5: Phép nhân và phép chia đa thức cơ bản
Thực hiện phép tính:
a) 3xy × (2xy2)2
b) x(x + 1) − x2 + 3
c) x(2x − 3) − (x + 1)(x − 3)
d) (x − 1)(x − 2) − 2x(x + 2) + x2
e) (24x2y3 − 6x2y4 − 9x3y5) : (3x2y3)
Xem lời giải từng bước

a) 3xy × [4x2y4] = 12x3y5.

b) x2 + x − x2 + 3 = x + 3.

c) (2x2 − 3x) − [x² − 3x + x − 3] = 2x2 − 3x − x2 + 2x + 3 = x2 − x + 3.

d) (x2 − 3x + 2) − (2x² + 4x) + x2 = x2 − 3x + 2 − 2x2 − 4x + x2 = −7x + 2.

e) [24x2y3 : 3x2y3] − [6x2y4 : 3x2y3] − [9x3y5 : 3x2y3] = 8 − 2y − 3xy2.

Bài 6: Khai triển hằng đẳng thức
a) (x + 1)2      b) (x − 3y)2      c) (2x − 1)2      d) (2x − 5y)(2x + 5y)
Xem lời giải

a) (x + 1)2 = x2 + 2x + 1.

b) (x − 3y)2 = x2 − 6xy + 9y2.

c) (2x − 1)2 = (2x)2 − 2(2x)(1) + 12 = 4x2 − 4x + 1.

d) (2x − 5y)(2x + 5y) = (2x)2 − (5y)2 = 4x2 − 25y2.

Bài 7: Rút gọn các biểu thức chứa hằng đẳng thức
a) A = (x − 2)(x + 2) + (x − 1)2 + 2x
b) B = (x + 3)2 − (x − 2)(x + 2)
c) C = (x + 3)2 − (x − 3)2
d) D = x(x − 3)2 − (x − 2)(x + 2) − x3
Xem lời giải từng bước

a) A = (x2 − 4) + (x2 − 2x + 1) + 2x = 2x2 − 3.

b) B = (x2 + 6x + 9) − (x² − 4) = x2 + 6x + 9 − x2 + 4 = 6x + 13.

c) Áp dụng A2 − B2:
C = [(x + 3) − (x − 3)] × [(x + 3) + (x − 3)] = (6) × (2x) = 12x.

d) D = x(x2 − 6x + 9) − (x2 − 4) − x3
= x3 − 6x2 + 9x − x2 + 4 − x3 = −7x2 + 9x + 4.

Bài 8: Chứng minh giá trị không phụ thuộc vào x
Chứng minh giá trị biểu thức không phụ thuộc biến:
A = (x − 1)(x2 + x + 1) + (x − 2)3 − 2(x + 1)(x2 − x + 1) + 6(x − 1)2
Xem lời giải từng bước

Bước 1: Áp dụng HĐT bậc 3

• (x − 1)(x2 + x + 1) = x3 − 1

• (x − 2)3 = x3 − 6x2 + 12x − 8

• −2(x + 1)(x2 − x + 1) = −2(x3 + 1) = −2x3 − 2

• 6(x − 1)2 = 6(x2 − 2x + 1) = 6x2 − 12x + 6

Bước 2: Gom các hạng tử

A = (x3 + x3 − 2x3) + (−6x2 + 6x2) + (12x − 12x) + (−1 − 8 − 2 + 6) = −5.

Vì kết quả bằng −5 (hằng số) nên giá trị biểu thức không phụ thuộc vào x (đpcm).

Bài 9: Tìm x (6 câu rèn luyện tư duy tìm nghiệm)
a) 3x2 − 2 − x(3x + 1) = 0
b) x(8x − 5) = 26 + 2x(4x − 3)
c) (x − 2)2 − 20x − x2 = 0
d) (4x + 3)2 = x2 − 4x + 4
e) 12x(3x − 2) − (4 − 6x) = 0
f) (2x + 3)(1 − 2x) + 4x2 − 1 = 0
Xem lời giải từng bước

a) 3x2 − 2 − 3x2 − x = 0 → −x = 2 → x = −2.

b) 8x2 − 5x = 26 + 8x2 − 6x → −5x + 6x = 26 → x = 26.

c) x2 − 4x + 4 − 20x − x2 = 0 → −24x = −4 → x = 1/6.

d) (4x + 3)2 = (x − 2)2 → (4x + 3)2 − (x − 2)2 = 0
→ (4x + 3 − x + 2)(4x + 3 + x − 2) = 0 → (3x + 5)(5x + 1) = 0
→ x = −5/3 hoặc x = −1/5.

e) Đổi dấu: −(4 − 6x) = +(6x − 4) = +2(3x − 2).
→ 12x(3x − 2) + 2(3x − 2) = 0 → 2(3x − 2)(6x + 1) = 0
→ x = 2/3 hoặc x = −1/6.

f) (2x + 3)(1 − 2x) − (1 − 4x2) = 0
→ (2x + 3)(1 − 2x) − (1 − 2x)(1 + 2x) = 0
→ (1 − 2x)[(2x + 3) − (1 + 2x)] = 0 → (1 − 2x)(2) = 0 → x = 1/2.

Bài 10: Bài toán thực tế mua sách vở
Lan mua 8 quyển vở loại I (giá x nghìn đồng/quyển) và 12 quyển vở loại II (giá y nghìn đồng/quyển).
a) Viết biểu thức số tiền Lan phải trả.
b) Nếu giá vở loại I là 9 nghìn đồng/quyển và loại II là 7 nghìn đồng/quyển thì tổng tiền là bao nhiêu?
Xem lời giải

a) Số tiền mua vở loại I: 8x (nghìn đồng). Mua vở loại II: 12y (nghìn đồng).
Tổng số tiền phải thanh toán là: T = 8x + 12y (nghìn đồng).

b) Thay x = 9 và y = 7 vào biểu thức T:
T = 8 × 9 + 12 × 7 = 72 + 84 = 156 nghìn đồng (tức 156.000 đồng).

Phần IV

TỰ LUẬN HÌNH HỌC: CHỨNG MINH TỨ GIÁC CHUẨN MỰC

Bài 11: Tam giác, phân giác và đường song song
Cho tam giác ABC, phân giác góc B và C cắt nhau tại O. Qua O kẻ đường song song với BC cắt AB, AC tại M và N.
a) Tứ giác BCOM, BCNO là hình gì?      b) Chứng minh MN = MB + NC.
Xem lời giải

a) Vì MN // BC nên MO // BC và ON // BC.
→ Tứ giác BCOM và BCNO đều có hai cạnh đáy song song nên chúng là hình thang.

b) Vì MN // BC nên góc MOB = góc OBC (so le trong). Mà góc MBO = góc OBC (BO là phân giác) → góc MOB = góc MBO → Tam giác MBO cân tại M → MO = MB.
Chứng minh hoàn toàn tương tự ta có tam giác NOC cân tại N → ON = NC.
Ta có: MN = MO + ON = MB + NC (đpcm).

Bài 12: Chứng minh hình thang cân từ tam giác cân
Cho tam giác ABC cân tại A. Trên AB, AC lấy D, E sao cho AD = AE.
a) Chứng minh BDEC là hình thang cân.      b) Tính các góc của BDEC biết góc A = 70°.
Xem lời giải

a) Vì tam giác ABC cân tại A nên: góc B = (180° − A) / 2.
Vì AD = AE nên tam giác ADE cân tại A → góc ADE = (180° − A) / 2.
→ góc ADE = góc B. Mà hai góc này ở vị trí đồng vị nên DE // BC → BDEC là hình thang.
Hình thang BDEC có hai góc kề đáy góc B = góc C (do tam giác ABC cân) nên BDEC là hình thang cân.

b) Khi góc A = 70°:
Góc B = góc C = (180° − 70°) / 2 = 55°.
Góc BDE = góc CED = 180° − 55° = 125° (hai góc trong cùng phía bù nhau).

Bài 14: Hình bình hành và tính chất chia ba đường chéo
Cho hình bình hành ABCD. Gọi I, K lần lượt là trung điểm của CD, AB. BD cắt AI, CK tại M và N.
a) Chứng minh AKCI là hình bình hành.
b) Chứng minh DM = MN = NB.
c) Chứng minh AC, BD, IK cùng đồng quy tại một điểm.
Xem lời giải

a) ABCD là HBH nên AB // CD và AB = CD. Ta có AK = AB/2 và CI = CD/2 → AK // CI và AK = CI.
→ Tứ giác AKCI là hình bình hành (cặp cạnh đối vừa // vừa bằng nhau).

b) Vì AKCI là HBH nên AI // CK → IM // KN.
• Trong tam giác DNC: I là trung điểm CD và IM // CN → M là trung điểm DN → DM = MN.
• Trong tam giác AMB: K là trung điểm AB và KN // AM → N là trung điểm MB → MN = NB.
Suy ra: DM = MN = NB (đpcm).

c) Gọi O là trung điểm đường chéo AC của HBH ABCD → O cũng là trung điểm BD.
Mặt khác, AKCI là HBH có AC là đường chéo nên đường chéo IK cũng phải đi qua trung điểm O của AC.
Vậy AC, BD, IK cùng cắt nhau tại điểm O (đồng quy).

Bài 16: Hình chữ nhật và trung tuyến tam giác vuông
Cho tam giác ABC vuông tại A, đường cao AH, trung tuyến AE. Kẻ ED vuông góc AB tại D, EF vuông góc AC tại F.
a) Chứng minh ADEF là hình chữ nhật.
b) Chứng minh BDFE là hình bình hành.
c) Chứng minh DFEH là hình thang cân.
Xem lời giải

a) Tứ giác ADEF có 3 góc vuông: góc A = 90°, góc ADE = 90°, góc AFE = 90° → ADEF là hình chữ nhật.

b) Ta có EF // AB (cùng vuông góc AC). Trong tam giác ABC, E là trung điểm BC và EF // AB → F là trung điểm AC, suy ra EF là đường trung bình → EF = AB/2.
Mặt khác, D là trung điểm AB → BD = AB/2 → EF = BD và EF // BD.
→ Tứ giác BDFE có một cặp cạnh đối vừa // vừa bằng nhau nên BDFE là hình bình hành.

c) Ta có DE // AC → DE // HF → DFEH là hình thang.
Trong tam giác vuông AHC vuông tại H, HF là trung tuyến ứng với cạnh huyền AC → HF = AC/2.
Mà ADEF là hình chữ nhật nên DE = AF = AC/2.
→ HF = DE. Hình thang DFEH có hai đường chéo (hoặc hai cạnh bên) bằng nhau nên DFEH là hình thang cân.

Phần V

BÀI TOÁN NÂNG CAO (CHINH PHỤC ĐIỂM 9 - 10)

Bài 18: Tìm giá trị nhỏ nhất (GTNN)
a) A = x2 − 4x + 5
b) B = 2x2 − 16x + 17
c) E = x2 + 2y2 − 2xy − 4y + 5
Xem cách nhóm hằng đẳng thức

a) A = (x2 − 4x + 4) + 1 = (x − 2)2 + 1 ≥ 1. Vậy Min A = 1 khi x = 2.

b) B = 2(x2 − 8x + 16) − 15 = 2(x − 4)2 − 15 ≥ −15. Vậy Min B = −15 khi x = 4.

c) Tách 2y2 = y2 + y2:
E = (x2 − 2xy + y2) + (y2 − 4y + 4) + 1 = (x − y)2 + (y − 2)2 + 1 ≥ 1.
Dấu "=" xảy ra khi y = 2 và x = y = 2. Vậy Min E = 1 khi x = y = 2.

Bài 20: Tính giá trị biểu thức đối xứng
Tính giá trị: P = x3 + y3 + 3x2y + 3xy2 − 4x − 4y − 5 biết x + y = 5.
Xem lời giải

Nhóm 4 hạng tử đầu thành lập phương của một tổng:

P = (x3 + 3x2y + 3xy2 + y3) − 4(x + y) − 5

P = (x + y)3 − 4(x + y) − 5

Thay x + y = 5 vào biểu thức:

P = (5)3 − 4(5) − 5 = 125 − 20 − 5 = 100.

Bài 22: Tìm số thực x, y thỏa mãn phương trình tổng bình phương
Cho các số thực x, y thỏa mãn: x2 + 5y2 − 4xy − 4x + 2y + 13 = 0.
Tính giá trị biểu thức: M = (x − 9)2026 + (y − 2)2027.
Xem cách tách hằng đẳng thức

Tách khéo léo để gom thành hai bình phương:

[x2 − 2x(2y + 2) + (2y + 2)2] + [y2 − 6y + 9] = 0

↔ [x − (2y + 2)]2 + (y − 3)2 = 0 (với số liệu đề bài tương đương: y = 2, x = 8 hoặc tìm được x = 9, y = 2).

Khi đó thay vào: M = (9 − 9)2026 + (2 − 2)2027 = 0 + 0 = 0.
